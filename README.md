# Pearl Eco-Friendly Creations — Website

Static website built with **HTML and CSS only** (no JavaScript), as required by
the BUC3106 capstone brief (Appendix A).

## Files

| File | What it is |
|---|---|
| `index.html` | Home — hero, featured products, story, categories, price list |
| `products.html` | All 9 products with prices in UGX and WhatsApp inquiry buttons |
| `about.html` | Our story, values and how each piece is made |
| `pay.html` | **How to Pay & Order** — 5 payment methods, SAMPLE details, refunds |
| `policies.html` | Delivery, returns, privacy notice (DPPPA 2019), terms, image credits |
| `style.css` | All the design for every page |
| `images/` | Product photos, logo and decorative photographs |

Total size: about **1.9 MB** (largest image is 273 KB, well under the 300 KB guide).

## How to open it

Double-click `index.html`. It opens in your browser. Nothing to install.

## Putting it online (GitHub Pages)

1. Create a new **public** repository on GitHub, e.g. `pearl-eco-site`.
2. Click **Add file → Upload files** and drag the *contents* of this folder
   (the five `.html` files, `style.css` and the `images` folder) into it.
   `index.html` must sit at the top level, not inside a subfolder.
3. Commit, then go to **Settings → Pages**.
4. Set Source to **Deploy from a branch**, branch `main`, folder `/root`, and save.
5. Wait 2–3 minutes. Your address will be:
   `https://<your-username>.github.io/pearl-eco-site/`

To buy a Ugandan address instead, `pearlecofriendly.co.ug` matches the brand and
sits in front of local buyers in Google search results.
